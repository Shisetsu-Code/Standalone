# Evidencia por proveedor

El [índice](index.json) enlaza la evidencia de los 35 proveedores del recolector. Cada archivo reúne las verificaciones históricas disponibles y los intentos registrados, incluidos los fallidos o pendientes. Los registros recientes incluyen importes, límites de fase y pasos cuando el intento los guardó.

Las referencias históricas incluyen ruta, huella SHA-256 y ubicación dentro del archivo cuando está disponible. Pueden apuntar a archivos locales, a una versión anterior o a capturas privadas. La presencia de una referencia documenta la procedencia. Consultá el estado de cada modo para saber qué se verificó.

El respaldo publica resúmenes saneados. Los mensajes originales con sesiones y credenciales se conservan en el equipo de trabajo. El inventario general incluye juegos fuera del corte histórico y proveedores que todavía tienen evidencia parcial.
